# Данные

Проект использует микроданные выборочного обследования рабочей силы Росстата за
2010–2023 годы. Исходные SPSS-файлы доступны в публичной папке:

https://disk.yandex.ru/d/W2tG4krgbjk4mw

Скачайте файлы `.sav` и поместите их непосредственно в `data/raw/`. Кодбуки из
папки источника полезны для проверки кодировки переменных, но для запуска
пайплайна не требуются.

```text
data/raw/
├── bd_ors_2010-2012.sav
├── bd_ors_2013-2015.sav
├── ...
└── bd_ors_2023.sav
```

Каталоги `raw/` и `processed/` исключены из Git: полный набор содержит более
12 млн наблюдений. После подготовки данных команда `labor-market build` создаёт
Parquet-файлы в `data/processed/`, разбитые по годам.

Источник: Росстат. Дата доступа к учебной копии набора: 12 сентября 2026 года.
Перед повторным распространением исходных файлов проверьте актуальные условия
использования на стороне источника.
